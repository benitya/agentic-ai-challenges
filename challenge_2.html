CHALLENGE 02

Frugal Agentic AI

The Frugal Agentic AI Challenge

Can a team of cooperating AI agents deliver useful answers while minimising energy consumption and communication on a small network of low-power computers?

Draft specification v0.1  |  Subject to review by the challenge chairs
◎

What is this challenge?

The challenge investigates multi-agent systems running on a common, resource-constrained platform. Teams design their own agent harnesses, including roles, prompts, routing, coordination, memory and validation, to operate effectively within the defined constraints.

The reference setup uses five low-power nodes (e.g. Raspberry Pi 5), with model weights selected by the organisers and an isolated network.

ⓘThe challenge specification is currently a draft and the proposed setup, models and evaluation rules are subject to review.
♧

The central question

How much useful capability can a coordinated, resource-efficient multi-agent system retain while reducing energy and compute requirements?

Reference setup

Five nodes, one common platform

The proposed setup uses five low-power computing nodes connected through an isolated network. Each node runs a model selected and installed by the organisers. Teams design their own agent harnesses, including roles, prompts, routing, coordination and memory.

Tasks

Two proposed tasks
01

Single query

Answer independent prompts, such as questions about passages, summaries and drafting tasks.

02

Multi-turn conversation

Handle a scripted conversation with evolving requirements and retain relevant context.

Task details, example prompts and constraints remain subject to review.
⇧

Submission requirements

What teams will submit
  • Setup code for five agents (one per node)
  • Connection self-test
  • Gateway implementing the challenge API
  • Configuration (roles, prompts, routing, memory)
  • Method description (maximum 2 pages)
Model weights are provided by the organisers. Packaging, dependencies and size limits are TBD.
