CHALLENGE 02

Frugal Agentic AI

The Frugal Agentic AI Challenge

Can a handful of agents powered by open-source models perform effectively on constrained hardware while reducing the resources required to run them?

What is this challenge?

The challenge investigates multi-agent systems running on a common, resource-constrained platform. The reference setup uses four Raspberry Pi 5 nodes with a pinned llama.cpp build, model weights selected by track and an isolated network.

Teams can explore how their agent harnesses coordinate, route work, validate outputs, use memory and synthesise results within the defined constraints.

The central question

How much useful capability can a coordinated, resource-efficient multi-agent system retain while reducing energy and compute requirements?
